# 08 · Opportunity and news sourcing

## Real shared opportunity pipeline

DEMO_MODE defaults false. Production shows no seeded sample opportunities or sample semester. Sourced news and words remain. Manual cleanup protects student references; see [deployment guide](../DEPLOY-REPLIT.md).

1. **Group/cache:** normalized topics, grade band 9–10/11–12 and broad region (state/virtual/US); coverage checks all selected interests, with up to five topic groups queued per request. Queries never contain names, IDs, schedules or private goals. Both explicit search buttons check the shared catalog for good, recent eligible active matches covering every selected interest and three Free/three Paid in total; full coverage costs no new search, even when AI is off or quotas are reached.
2. **Request/queue:** durable OpportunitySearchRequest binds a student to public group work. Coalesce duplicate visits/clicks. Initial search requires a click; monthly refresh is rolling 30 days for students who previously completed a search. Search only missing interests; when all interests are covered but a bucket is short, target its least-covered topics. Search again reserves one manual slot plus at most one meaningful-interest-change bonus only when new web work is needed. Complete catalog reuse is free. Complete/empty settlement charges once; failures, interrupted work and caps do not charge manual allowance. Repeated edits do not trigger unlimited automatic searches.
3. **Budget/search:** recheck current coverage immediately before reserving global monthly AI usage plus DISCOVERY_MONTHLY_BUDGET for a group run. Another student may have filled the gap while work was queued. Failures remain counted as paid attempts. At most two provider searches (short Free/Paid buckets), ten candidate URLs and five extraction calls. OpenAI Responses web-search preview or Anthropic search lives only in adapters. No automatic paid-node retries/replay.
4. **Fetch:** official public HTTPS only; no credentials, alternate ports or private DNS/IP destinations. Pin DNS for every connection; prefer IPv4 with one bounded transport-failure fallback. Respect robots, cache rules per run, fail closed except robots 404. Allow only same-host or canonical apex/www redirects; revalidate DNS/robots at each hop. Fifteen-second request timeout, 1 MiB compressed/decompressed bound, up to twenty HTTP attempts including robots/redirects, and a total run deadline. Read the page plus up to three same-origin rules/FAQ/eligibility/fees links. Strip scripts/navigation, keep up to 18,000 readable characters, URL/title/hash/check date. Inaccessible, bot-blocked or JavaScript-only pages may be unusable.
5. **Extract:** AI_MODEL_EXTRACTION uses nullable strict JSON with literal page evidence for names, organizer, grades/age, format/region, fees/aid, commitment, skills/tags, deadline, application status, activity date, eligibility notes and requirements. Unknown facts stay unknown. Fetched content is data, never instructions. Code checks real dates, literal quoted evidence, grade bounds and explicit free participation; free resources or a free application do not establish free participation.
6. **Verify active:** trusted organizer domains, owner-reviewed DISCOVERY_TRUSTED_DOMAINS or education/government sources are required; .org alone is not proof. Verified also requires evidenced grade range, format and current activity. Competitions need a confirmed future official deadline. Programs/internships/scholarships need a future official deadline or fresh explicit open/rolling statement. Clubs/volunteering need open sign-up or current/upcoming activity. Reject closed, past, stale (>30 days), unverified or ineligible results. Unknown cost can remain verified for an established organizer, but goes into Paid labeled “Cost not confirmed — check the official site.” Only an explicit checked free-cost fact earns Free. High/unclear fees at unestablished organizers are flagged and never stretched.
7. **Store/select:** dedupe canonical official domain + normalized name, preserve program IDs, store public snapshots and group keys. SQL/rules rank fit, deadline urgency (prefer at least seven days), type/commitment variety and at most one eligible outside-interest stretch item. Respect grade/region/time/readiness; minimum-age requirements remain explicit checks because Pathway does not collect birth dates. Saved/dismissed items leave picks. Reasons down-rank similar interest tags, high effort, paid or in-person options as applicable. Return up to three Free/three Paid, never invented substitutes. Save/dismiss refills preserve other bucket picks and cost no AI.
8. **Prepare once:** shared official pages become LangChain Documents and ~500-word chunks with ~50-word overlap. SQL owns text/citations; vector metadata contains only chunkId, opportunityId, sourceUrl, pageTitle, checkedAt. Batches ≤20 chunks, four embedding calls and 100 vector upserts/run. Skip unchanged source/model/dimension/store identity; changing the index re-ingests. Use opportunities namespace. A per-program lock prevents duplicate simultaneous embedding. Catalog results survive an optional indexing failure.
9. **Student scope/answers:** server computes current StudentPick + Interested membership, excluding feedback and expired/inactive picks. Single-program retrieval must be in this set; my_opportunities uses its IN filter. Query dense top ten, load SQL text and revalidate scope/model/store/snapshot, rerank with keywords to five passages. Refine at most twice more in LangGraph. Structured deadline/cost/eligibility/status comes from SQL/rules, exact textual excerpts must be verified and cited, and cross-program answers are grouped. No supported answer means the official-page no-answer message and link. Requirements updates remain approval proposals.
10. **Jobs/maintenance:** timer, owner cron and authenticated request-bound worker share a renewable lease. One group, one standalone program preparation and one source recheck per invocation; up to 25 due students refreshed. Monthly and seven-day-boundary rechecks invalidate changed/unreachable sources. Expiration removes picks while keeping Interested notes/checklists and cited deadlines. Standalone preparation uses the shared recheck/preparation allowance and a persistent public generation/month attempt marker; failures are not replayed on each visit. Monthly reconciliation retires only expired unreferenced chunks, keeps all student references and removes orphan vectors, bounded to 100 pages of IDs.

## Graceful states and diagnostics

Missing search configuration/consent, discovery off or global allowance: explain the web-search blocker without sample fillers; a complete active catalog remains reusable. Shared monthly limits are checked against current configuration and persisted usage, so raising a cap clears a historical limited status without resetting counters. Missing embedding/vector setup or dimension mismatch disables Q&A independently; verified search/catalog features continue. Search results can be partial, empty or failed with Try again. Preparing details indicates missing current chunks; Ask activates only after matching chunks exist. Safe failure records contain stage/code/public host/HTTP status, never raw SDK errors, prompts, keys or student data. Zero source pages/chunks explains zero Pinecone records; inspect source failures first.

Use AI_DISABLED=true to stop all paid AI, or AI_MONTHLY_LIMIT=0 to prevent new paid reservations. DISCOVERY_ENABLED=false stops live search; existing configured Q&A/preparation can still run. Set both discovery/recheck run caps to zero to pause those background attempts. Catalog selection, saves/refills, calendars and approvals continue without AI. UTC-month overall limits count attempts, while manual student search allowance counts completed searches in rolling cycles.

## Cost planning (checked 2026-11-02)

Illustration using the existing compatible configuration: GPT-4.1 mini search ($0.40 input/$1.60 output per million tokens), GPT-5 nano extraction ($0.05/$0.40), and text-embedding-3-small ($0.02/million input tokens). Non-reasoning web-search preview is $0.025/call, with search content token treatment described in provider pricing. These are rate examples, not a recommendation to select retired models: current docs mark older models deprecated (and GPT-4.1 nano shut down). Verify account availability and use a supported replacement through the separate settings.

For one group, two preview searches cost about $0.05 in search-tool fees. Illustratively, 100,000 extraction input tokens + 30,000 completion/reasoning tokens on the nano rates add $0.017; 40,000 embedding tokens add $0.0008. Search input/output and provider differences add to that. Plan roughly **$0.05–$0.10 per newly searched group**, or **$0–$0.50 per first student search/manual or monthly refresh** across zero to five unfunded shared groups. A changed-page recheck or standalone embedding is normally smaller (often under $0.03 with this configuration); unchanged snapshots skip extraction/embedding. These are illustrative totals, not guaranteed maxima. A full active shared catalog, saving/dismissing and same-bucket replacements cost **$0 in new AI calls**. Store-once ingestion avoids embedding the same public program for every student.

Pinecone storage/operations and plan minimums, Replit hosting, interactive Buddy questions, different model rates and taxes are additional. DiscoveryRun/DiscoveryUsage track attempts, searches, HTTP fetches, embeddings, vector writes, estimated tokens and a conservative heuristic cost ($0.03/search + $4/million estimated tokens + $0.001/embedding call + $0.00001/vector write). It is not the provider invoice or a dollar cap. Interrupted runs can have incomplete final usage. Check provider billing and set provider spend controls in addition to app count caps.

Primary sources: [OpenAI tool/model pricing](https://developers.openai.com/api/docs/pricing), [mini](https://developers.openai.com/api/docs/models/gpt-4.1-mini), [nano](https://developers.openai.com/api/docs/models/gpt-5-nano), [small embeddings](https://developers.openai.com/api/docs/models/text-embedding-3-small), [Pinecone cost](https://docs.pinecone.io/guides/manage-cost/understanding-cost). Recheck availability/rates before enabling paid features. No paid live calls were used to estimate or test this rebuild.

## News for you

News remains the real sourced starter catalog, with publisher/date/link; words remain in the existing real vocabulary data. This rebuild does not implement live news ingestion. Future ingestion should use reputable licensed feeds, preserve citations, avoid fabricated summaries, dedupe URLs and keep honest topic-empty states. Today respects the student’s word/news settings.

Foreground work handles a search group or a standalone program preparation per call, keeping slow providers within the web request window. Timer/cron work shares a three-minute run deadline, checked before funding another stage; a final in-flight provider call can finish after that deadline. Paid nodes are never automatically replayed.
